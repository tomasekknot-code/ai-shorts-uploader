Privacy Policy

AI Shorts Uploader - last updated 26 November 2026

Who this covers

AI Shorts Uploader is used by one person: its developer. It has no other users, no sign-up and no hosted service. This policy describes how the application handles data from the single Google Account that authorizes it.

What the application accesses

With the account owner's consent, the application uses these Google API scopes:

  • youtube.upload - to upload videos to the owner's own channel.
  • youtube.readonly - to read back the status of those uploads.
  • yt-analytics.readonly - to read view and subscriber statistics for the owner's own videos.

How data is stored

The OAuth token and the channel statistics are stored only in local files on the developer's own computer. Nothing is uploaded to a server, no database is used, and no analytics or tracking services are involved.

What is not done

The application does not sell, share, transfer or publish any data. It does not access other people's channels or content, and it does not read, modify or delete anyone else's videos. No data is used for advertising or for training machine learning models.

Google user data and limited use

The application's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

The stored token can be revoked at any time from the Google Account permissions page, and the local token and statistics files can be deleted at any time. Deleting them removes all data the application holds.
